كلــونلصوتـــي في ElevenLabs

خطوات الحلقة 13 من «بتعلّم Claude قدامكم»: عملت كلون لصوتي في ElevenLabs، وClaude كتبلي سكريبت بيبعت كل سطر من الريل للـ API ويرجّعه ملف MP3 بصوتي.

Watch the reelشوف الريلAll episodesكل الحلقات
  1. 01

    سجّل دقيقة لدقيقتين بصوتك

    ElevenLabs بتقول إن دقيقة لدقيقتين صوت نضيف كفاية، ومتزوّدش عن 3 دقايق. صوت واحد بس، من غير صدى ولا دوشة، وبنفس الطريقة اللي عايز الكلون يتكلم بيها، لأنه بيقلّد السرعة والنبرة واللهجة.

    دليل Instant Voice Cloning الرسمي ↗
  2. 02

    اعمل Instant Voice Clone

    في ElevenLabs افتح Voices ودوس علامة +، واختار Instant Voice Clone. ارفع التسجيل، سمّي الصوت، وأكّد إن ده صوتك ومن حقك تعمله كلون، وبعدين Save voice.

  3. 03

    هات رقم الصوت (voice_id)

    كل صوت ليه رقم. تقدر تشوف أصواتك كلها بالـ API ده (حط المفتاح بتاعك مكان الكلام):

    curl -H "xi-api-key: YOUR_KEY" https://api.elevenlabs.io/v2/voices
  4. 04

    خبّي المفتاح في .env

    خد الـ API key من حسابك في ElevenLabs، وحطه في ملف إعدادات اسمه env (بنقطة في أوله) جوه فولدر المشروع. متكتبوش جوه الكود ولا تبعته لحد.

    ELEVENLABS_API_KEY=paste-your-key-here
  5. 05

    خلّي Claude يكتب السكريبت

    افتح Claude Code في فولدر المشروع واطلب منه السكريبت. هو بيبعت السطر لـ text-to-speech بالـ voice_id بتاعك، ويحفظ الصوت ملف MP3.

    Write tts.mjs: read script.json, send each scene's vo to the ElevenLabs text-to-speech API (POST /v1/text-to-speech/{voice_id}, key from ELEVENLABS_API_KEY), save vo/01.mp3, 02.mp3 … Never print the key.
  6. 06

    شغّله على الريل

    ده نفس الأمر اللي في الريل: 3 سطور اتقالوا بصوتي واتحفظوا ملفات في فولدر vo.

    node tts.mjs jobs/_demo13
  7. 07

    اسأل Claude هو عمل إيه

    ده الأمر التاني اللي في الريل: Claude بيقرا السكريبت ويشرحه في 3 سطور، من غير ما يطبع أي مفتاح.

    claude -p "Read tts.mjs and config.json. Answer in exactly 3 lines, English, never print any id or key: 1) what it sends to ElevenLabs 2) which model 3) what files it saves." --allowedTools Read

نصايح صغيرة

  • اعمل كلون لصوتك إنت بس، أو لحد معاك موافقته. ElevenLabs بتطلب منك تأكّد ده قبل ما تحفظ.
  • الكلون بيقلّد كل حاجة في التسجيل، حتى الدوشة وصوت الشفايف. سجّل في أوضة هادية.
  • المفتاح زي الباسورد: لو اتسرّب امسحه من حسابك واعمل واحد جديد.
