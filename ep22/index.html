كاروسيــلبهويتـــي

خطوات الحلقة 22 من «بتعلّم Claude قدامكم»: إزاي تخلّي Claude Code يعمل كاروسيل إنستجرام بهويتك (الألوان والخط واللوجو) وصوره PNG جاهزة للنشر، من غير فوتوشوب.

Watch the reelشوف الريلAll episodesكل الحلقات
  1. 01

    هويتك في ملف

    لازم يكون عندك ملف CLAUDE.md فيه ألوانك وخطوطك ولوجوك (الحلقة 19). كده كل صورة هتطلع بيهم من غير ما تقول.

  2. 02

    افتح Claude Code

    افتح PowerShell في فولدر الهوية، ومنه افتح Claude Code بالأمر اللي تحت.

    claude
  3. 03

    اطلب الكاروسيل

    قوله عدد الصور والمقاس والموضوع، وإنه يحفظهم صور. غيّر الموضوع لموضوعك:

    Make a 5 slide Instagram carousel, 1080x1350, in my brand from CLAUDE.md, with 5 tips about my topic. Build each slide as HTML, then save each one as a PNG with headless Chrome in carousel/
  4. 04

    وافق على Chrome

    عشان يحوّل كل صفحة لصورة، هيطلب إذن يشغّل Chrome في الخلفية. وافق عليه.

  5. 05

    راجع الصور

    افتح فولدر carousel وبص على كل صورة: الكلام جوه الحواف، ومفيش حاجة مقطوعة. لو في حاجة، قوله يصلّح الصورة دي بس.

  6. 06

    انشرهم كصور

    ارفع الصور بالترتيب ككاروسيل على إنستجرام أو تيك توك.

نصايح صغيرة

  • صورة لكل فكرة، وجملة قصيرة في كل صورة.
  • أول صورة هي الوعد، وآخر صورة فيها اللي عايز الناس تعمله.
  • عندي في الاستوديو أداة Claude كتبها بتعمل الكاروسيل من خطوات الحلقة بأمر واحد.
