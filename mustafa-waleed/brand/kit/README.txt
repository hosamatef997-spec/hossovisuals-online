هوية مصطفى — أوشحة وأرواب التخرّج
الشعار: رقم 1 «الحرف صار وشاح»

00-Brand-Guide   دليل الهوية (PDF): الفكرة، النسخ، الألوان، الخطوط، التطريز، الممنوعات
01-Logo          كل نسخ الشعار
   Primary       الشعار الأساسي ويه الجملة الإنجليزية
   Wordmark      الاسم بس (للسوشال والأحجام الصغيرة)
   Symbol        الرمز لوحده (البروفايل، الختم، الستيكر)
   Embroidery    نسخة التطريز المبسّطة
   بكل مجلد: SVG و PDF للمطبعة والتطريز، PNG شفاف كبير (3000) و small (1000)
   FullColour = الألوان الأصلية على خلفية فاتحة
   Reversed   = للخلفيات الغامقة والعنابي
   Burgundy / Black / White / Gold = لون واحد
02-Social        صورة البروفايل، أغلفة الهايلايت، قوالب البوست والستوري، العلامة المائية
                 Template = فاضي (شفاف مكان الصورة)  ·  Example = مثال جاهز
03-Colours       الألوان وأرقامها HEX / RGB / CMYK
04-Fonts         Poppins (الإنجليزي) و Alexandria (العربي)، مجانيين برخصة OFL
05-Mockups       صور العرض

للمطبعة والتطريز: ابعثوا SVG أو PDF.
للسوشال والواتساب: PNG.
