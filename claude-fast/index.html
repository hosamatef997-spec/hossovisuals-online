أسرع لحــد×2.5

Fast mode في Claude Code: أمر واحد ‎/fast بيخلّي نفس الموديل يرد أسرع لحد مرتين ونص، بنفس الجودة، بس سعر التوكن أعلى. ولو عندك اشتراك، بيتحسب من رصيد إضافي مش من باقتك.

All episodesكل الحلقات
  1. 01

    إيه هو Fast mode؟

    وضع سرعة عالية لنفس الموديل: Anthropic بتقول إنه بيخلّي الرد أسرع لحد 2.5 مرة، بنفس جودة الموديل، بس سعر التوكن أعلى. مش موديل أضعف، ده نفس الموديل بيتشغّل أسرع.

    Fast mode (Claude Code Docs) ↗
  2. 02

    شغّله بـ ‎/fast

    في Claude Code اكتب ‎/fast واضغط Enter. ينفع تكتبه وClaude شغال: الرد اللي شغال يكمّل بسرعته العادية، والسرعة تبدأ من الرد اللي بعده. ونفس الأمر ‎/fast يقفله.

    Fast mode (Claude Code Docs) ↗
  3. 03

    نفس الجودة، بس أغلى

    الموديل والجودة زي ما هم، اللي بيتغيّر السعر: مع Fable 5.2 مثلًا التوكن بـ 16 دولار للمليون داخل و80 للمليون خارج في Fast mode. استخدمه لما الوقت أهم من الفلوس: تعديل سريع قبل تسليم، أو شغل بتستناه وإنت قاعد.

    Fast mode pricing (Claude Code Docs) ↗
  4. 04

    لو مشترك: رصيد إضافي

    على Pro وMax وTeam وEnterprise، Fast mode مش داخل في حدود باقتك: بيتحسب من usage credits (رصيد إضافي). يعني باقتك مش بتتلمس، بس لازم يكون عندك رصيد إضافي مفعّل.

    Fast mode (Claude Code Docs) ↗
  5. 05

    قبل ما تشغّله

    مع Fable 5.2 محتاج Claude Code إصدار 2.1.321 أو أحدث. ولو الموديل اللي إنت عليه مش بيدعم Fast mode، Claude Code بيقولك أو بيبدّل لموديل بيدعمه، ولو غيّرت لموديل مش بيدعمه بيتقفل لوحده.

    Claude Code changelog ↗
  6. 06

    عايز شغلك أسرع؟

    لو عايز ريلز وموشن وفيديوهات لبراندك من غير ما تستنى، ابعتلي على الواتساب وأقولك السعر حسب اللي محتاجه.
