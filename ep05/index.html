سطّبClaude Code على جهـــازك

خطوات الحلقة الخامسة من «بتعلّم Claude قدامكم»: الاشتراك اللي محتاجه، وأمر التسطيب الرسمي، وإزاي تتأكد إنه اشتغل، وأول تشغيل في فولدر مشروعك.

Watch the reelشوف الريلAll episodesكل الحلقات
  1. 01

    محتاج اشتراك

    Claude Code شغال مع اشتراك Pro أو أعلى (Max، أو Team، أو Enterprise)، أو حساب Console بتاع الـ API. الباقة المجانية مش بتشغّله.

    claude.com/pricing ↗
  2. 02

    افتح PowerShell

    على ويندوز: دوس زرار الويندوز، واكتب PowerShell، وافتحه. على الماك: افتح Terminal.

  3. 03

    انسخ الأمر الرسمي

    ده أمر التسطيب من صفحة Claude Code الرسمية. انسخه، وحطه في PowerShell، ودوس Enter. التسطيب مش بيبيّن تقدّم وهو شغال، فاستنى لحد ما يخلص.

    irm https://claude.ai/install.ps1 | iex
    صفحة البداية الرسمية ↗
  4. 04

    على الماك

    على الماك أو لينكس، الأمر ده بدل اللي فوق، في Terminal:

    curl -fsSL https://claude.ai/install.sh | bash
  5. 05

    اتأكد إنه اشتغل

    اقفل الشباك وافتح PowerShell جديد، واكتب الأمر ده. لو طلعلك رقم النسخة، يبقى كله تمام.

    claude --version
  6. 06

    اعمل فولدر للمشروع

    Claude Code بيشتغل جوه الفولدر اللي إنت فيه. اعمل فولدر جديد وادخل جواه:

    mkdir my-first-project; cd my-first-project
  7. 07

    شغّله وكلّمه

    اكتب claude ودوس Enter. أول مرة هيفتحلك المتصفح تسجّل دخول بحسابك، وبعدها هيسألك لو بتثق في الفولدر ده. قوله آه، وابدأ كلّمه بالعربي عادي.

    claude

نصايح صغيرة

  • لو PowerShell قالك إن claude مش موجود، اقفل الشباك وافتح واحد جديد. لو لسه، الصفحة الرسمية فيها جزء «Fix your PATH».
  • لو كتبت الأمر في CMD بدل PowerShell هيطلعلك إن irm مش معروف. اتأكد إن السطر بيبدأ بـ PS.
  • Claude Code بيحدّث نفسه لوحده، فمش محتاج تسطّبه تاني.
