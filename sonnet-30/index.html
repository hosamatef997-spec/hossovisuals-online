بوتك يقــفيـــوم 30

Anthropic هتقفل موديل Claude Sonnet 4.5 على Claude API يوم 30 نوفمبر 2026. لو عندك بوت أو أداة بتكلّم الـ API بالاسم ده، هتبطّل ترد. الحل إنك تغيّر اسم الموديل للبديل. دي الطريقة خطوة خطوة.

All episodesكل الحلقات
  1. 01

    مين محتاج يعمل حاجة

    أي حد عامل بوت أو أتمتة أو أداة بتبعت طلبات لـ Claude API بموديل claude-sonnet-4-5 (حتى لو بعده تاريخ). لو بتستخدم تطبيق Claude أو موقعه العادي بس، مفيش حاجة مطلوبة منك.

    Model deprecations (Anthropic docs) ↗
  2. 02

    دوّر على الاسم القديم

    افتح كود البوت أو إعدادات الأداة (n8n، Make، Zapier، أو ملف الكود) ودوّر على كلمة sonnet-4-5. هتلاقيها في خانة اسمها model غالبًا.

  3. 03

    غيّره لسونيت 5.5

    حط مكانه اسم البديل اللي Anthropic بتنصح بيه، واحفظ، وجرّب طلب واحد تتأكد إنه بيرد.

    claude-sonnet-5-5
  4. 04

    أو خلّي Claude يغيّره

    لو المشروع كبير وفيه ملفات كتير، افتح الفولدر في Claude Code (من تطبيق Claude Desktop) واكتبله الجملة دي. هيدوّر ويوريك التغييرات قبل ما يحفظها.

    دوّر على claude-sonnet-4-5 في المشروع كله وغيّره لـ claude-sonnet-5-5، ووريني كل ملف اتغيّر.
  5. 05

    خد بالك من دول

    لو شغال من خلال منصة تانية زي Amazon Bedrock أو Google Vertex، مواعيد القفل عندهم ممكن تختلف، شوف صفحة المنصة. وبعد التغيير جرّب البوت على كام سؤال حقيقي، لأن الموديل الجديد ممكن يرد بأسلوب مختلف شوية.
