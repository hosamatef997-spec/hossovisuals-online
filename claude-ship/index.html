Claudeبيصلّح الكود بنفســـه

من 23 نوفمبر 2026: Claude Ship. تلات وكلاء بيراجعوا الـ Pull Request، يصلّحوه، ويوافقوا على اللي قواعد فريقك بتسمح بيه. لسه تجريبي (beta) لباقات Team وEnterprise، على GitHub.

All episodesكل الحلقات
  1. 01

    إيه هو Claude Ship؟

    تلات وكلاء شغالين على الـ Pull Requests بتاعتك على GitHub: Code Review بيراجع، وPR Steward بيصلّح، وClaude Approvals بيوافق. Code Review متاح للكل من قبل كده، والاتنين التانيين لسه تجريبي.

    الإعلان الرسمي من Claude ↗
  2. 02

    الاختبار وقع؟

    PR Steward بيصلّح الاختبارات (CI) اللي وقعت، والتعارضات (merge conflicts)، وملاحظات المراجعة. وبعد كل تعديل بيكتبلك كومنت: غيّر إيه، وإزاي ترجّعه لو مش عاجبك.

    TechCrunch (23 نوفمبر) ↗
  3. 03

    إنت تكتب القواعد

    Claude Approvals بيمشي على ملف قواعد إنت بتكتبه جوّه الريبو بالكلام العادي، زي: «وافق لو التعديل صغير والاختبارات عدّت». اللي يعدّي القواعد يتوافق عليه، والباقي يروح لبني آدم. Anthropic بتنصح تشغّله الأول في وضع المراقبة بس (observe-only).

    TechCrunch ↗
  4. 04

    مين يقدر يستخدمه؟

    دلوقتي تجريبي (beta) لباقات Claude Team وEnterprise، وللريبوهات اللي على GitHub بس. تقدر تبدأ بريبو واحد، وتحط حد صرف شهري.

    صفحة Claude Ship ↗
  5. 05

    جرّبه على شغلك

    لو عندك Claude Code، اكتب الأمر /ship على الـ Pull Request بتاعك وهو يراجعه ويصلّحه. خلّي بالك: اقرا كل تعديل قبل ما تدمجه، خصوصًا أي حاجة فيها دفع أو باسوردات.

    9to5Mac: أمر /ship في Claude Code ↗
  6. 06

    عايز موقع لبراندك؟

    لو عايز موقع أو موشن أو ريلز لبراندك من غير وجع دماغ، ابعتلي على الواتساب وأقولك السعر حسب اللي محتاجه.
