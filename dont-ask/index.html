`Don't ask again`وباســـوردك

اختيار «Yes, and don't ask again» في Claude Code بيحفظ الأمر بالحرف في ملف .claude/settings.local.json. لو الأمر كان فيه باسورد أو مفتاح، بيتحفظ معاه. دي تلات خطوات تشيّك وتصلّح بيهم مشاريعك النهارده.

All episodesكل الحلقات

  1. إيه اللي حصل؟

    شركة الأمن Apiiro نشرت يوم 5 نوفمبر 2026 إنها دوّرت في GitHub العام ولقت 104,185 نسخة من الملف ده، منهم 1,122 نسخة فيها أسرار حقيقية: باسوردات قواعد بيانات، مفاتيح Supabase وAWS، ودخول SSH. Apiiro ماجربتش هل الأسرار دي لسه شغالة ولا لأ.

  2. ليه الملف ده؟

    لما تختار «Yes, and don't ask again» لأمر في التيرمنال، Claude Code بيحفظه كقاعدة allow في .claude/settings.local.json عشان مايسألكش تاني. Claude Code بيضيف الملف ده لـ git excludes على جهازك أول ما يعمله، بس لو الملف اتعمل باليد أو الريبو اتنسخ على جهاز تاني، ممكن يترفع مع باقي المشروع.

  3. 01

    شيّك اترفع ولا لأ

    افتح التيرمنال جوه فولدر المشروع واكتب الأمر ده. لو مطلعش حاجة، الملف عمره ما اترفع وإنت سليم. لو طلع سطر أو أكتر، كمّل الخطوة الجاية:

    git log --all --oneline -- .claude/settings.local.json
  4. 02

    غيّر الباسورد الأول

    لو الملف اترفع، افتح نسخه القديمة وشوف أي باسورد أو مفتاح كان فيه، وغيّره من الموقع بتاعه (قاعدة البيانات، Supabase، AWS…) قبل أي حاجة. مسح الملف لوحده مش كفاية، لأن تاريخ git والنسخ (forks) لسه شايلينه.

  5. 03

    شيله من git

    بعد ما تغيّر الأسرار، شيل الملف من git من غير ما تمسحه من جهازك، وضيفه لـ .gitignore عشان مايترفعش تاني:

    git rm --cached .claude/settings.local.json && echo .claude/settings.local.json >> .gitignore

  6. المرة الجاية

    ماتكتبش باسورد جوه الأمر نفسه. حطه في متغيرات البيئة (ملف .env مش مرفوع على git)، وفعّل secret scanning على GitHub عشان ينبهك لو حاجة اترفعت. أنا شيّكت مشاريعي وطلعت سليمة ✅
