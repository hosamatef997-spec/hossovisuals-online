يعني إيــهMCP؟

خطوات الحلقة العاشرة من «بتعلّم Claude قدامكم»: يعني إيه MCP، وإزاي تضيف برنامج لـ Claude Code بأمر واحد، وتسجّل دخول مرة واحدة، وتشوف حالته، وتشيله لو مش عايزه.

  1. 01

    يعني إيه MCP؟

    MCP (Model Context Protocol) معيار مفتوح بيوصّل Claude Code بأدواتك وبرامجك وقواعد البيانات. كل برنامج ليه «سيرفر MCP»، ولما توصّله، Claude يقرا من البرنامج ويشتغل فيه على طول، بدل ما تنسخ الكلام وتلزقه في الشات.

    صفحة MCP الرسمية ↗
  2. 02

    افتح PowerShell في فولدر شغلك

    الأوامر دي بتتكتب في PowerShell على ويندوز (أو Terminal على الماك) على طول، من غير ما تفتح Claude Code. البرنامج اللي هتضيفه بيتسجّل للفولدر ده بس (ده الافتراضي).

  3. 03

    ضيف البرنامج

    بعد add بتكتب نوع السيرفر (http)، وبعدين اسم تختاره، وبعدين لينك السيرفر. ده المثال الرسمي بتاع Notion من صفحة Claude Code.

    claude mcp add --transport http notion https://mcp.notion.com/mcp
  4. 04

    شوف حالته

    لو مكتوب Needs authentication يبقى فاضل تسجّل دخول. ولو مكتوب Connected يبقى شغال.

    claude mcp get notion
  5. 05

    سجّل دخول مرة واحدة

    هيفتحلك المتصفح تسجّل دخول في البرنامج وتوافق. أو افتح claude واكتب /mcp واختار البرنامج.

    claude mcp login notion
  6. 06

    اطلب عادي

    افتح claude في نفس الفولدر واطلب بالكلام، وهو يستخدم البرنامج لوحده. أول مرة هيسألك يستخدم الأداة ولا لأ.

    claude
  7. 07

    كل البرامج اللي عندك

    يطلعلك كل السيرفرات وحالة كل واحد.

    claude mcp list
  8. 08

    شيله لو مش عايزه

    claude mcp remove notion

نصايح صغيرة

  • وصّل بس السيرفرات اللي بتثق فيها: السيرفر اللي بيجيب كلام من النت ممكن يدخّل تعليمات غلط (prompt injection).
  • البرنامج بيتسجّل للفولدر اللي إنت فيه بس. عايزه في كل فولدراتك أو لفريقك كله؟ الأمر كامل في ملف الحلقة.
  • مش عارف لينك السيرفر؟ أغلب البرامج كاتبة أمر claude mcp add جاهز في صفحة المساعدة بتاعتها.
