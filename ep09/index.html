أهــم 5Skills للإديت والموشـــن

من الحلقة التاسعة من «بتعلّم Claude قدامكم»: عندي 124 Skill، ودول الخمسة اللي شغالين معايا كل يوم في الإديت والموشن، وكل واحد بيعمل إيه، ومنين تجيبه.

Watch the reelشوف الريلAll episodesكل الحلقات

  1. شوف عندك كام

    الـ Skills الشخصية بتاعتك في فولدر ‎~/.claude/skills. الأمر ده بيعدّهم في PowerShell:

    (ls ~/.claude/skills).Count
  2. 01

    HyperFrames

    بيحوّل صفحة HTML لفيديو: عناوين، وكابشن، وموشن، وكل فيديو في الاستوديو بتاعي بيتعمل بيه. بيتنزّل كـ Plugin رسمي (الحلقة 8):

    claude plugin install hyperframes@claude-plugins-official
  3. 02

    Remotion

    نفس الفكرة بس بـ React. الـ Skills دي من Remotion نفسهم، وبتعلّم Claude الطريقة الصح للأنيميشن والصوت والكابشن والرندر.

    npx skills add remotion-dev/skills
    Remotion Skills على GitHub ↗
  4. 03

    Motion Copy

    ده Skill عملته لنفسي بالطريقة بتاعة الحلقة 7: تبعتله فيديو عاجبك، ويعيده حركة بحركة (نفس التوقيت والزووم والبلور) بهويتك واسمك. اعمل واحد زيه: اطلب من Claude Code يعمل Skill من طريقة شغلك في نسخ الفيديوهات.

  5. 04

    Video Use

    إديت للفيديو بالكلام: بيفرّغ، ويقص، ويلوّن، ويحط كابشن، وبيسألك قبل ما ينفّذ. مفتوح المصدر على GitHub، وطريقة التسطيب في الصفحة.

    browser-use/video-use ↗
  6. 05

    Algorithmic Art

    خلفيات وأشكال بتتولّد بالكود (p5.js)، كل مرة شكل جديد. ده من مجموعة Skills الرسمية بتاعة Anthropic.

    anthropics/skills ↗

  7. اقرا الـ Skill قبل ما تستخدمه

    أول سطرين في أي SKILL.md بيقولولك هو بيعمل إيه وإمتى بيشتغل:

    type ~/.claude/skills/hyperframes/SKILL.md | select -first 3

نصايح صغيرة

  • مش محتاج تقول اسم الـ Skill: Claude بيقرا الوصف ويختار المناسب لطلبك.
  • لو عايز واحد معيّن، قوله اسمه في الطلب.
  • نزّل من مصادر بتثق فيها بس، واقرا SKILL.md الأول.
