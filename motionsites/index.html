موقع سينمائــيSkill مجانيـــة

شركة MotionSites نزّلت Skill مجانية اسمها MotionSites Web Builder، بتخلّي Claude يبني صفحات مواقع بشكل سينمائي بدل التصميم العادي اللي كل الـ AI بيطلّعه. دي طريقة التركيب خطوة بخطوة، ولو عايز موقع لبراندك من غير تعب، كلّمني.

Watch the reelشوف الريلAll episodesكل الحلقات

  1. إيه الـ Skill دي؟

    MotionSites Web Builder هي Skill مجانية من شركة MotionSites، نزلت على GitHub يوم 26 أكتوبر 2026. جواها 40 تصميم من أكتر التصاميم المحبوبة على موقعهم، وأكتر من 50 فيديو سينمائي و30 مجسم 3D شفاف، وأكتر من 55 تكنيك موشن بالكود. Claude بيكتب خطة دقيقة للموقع الأول، يبنيه، وبعدين بياخد سكرين شوت لشغله ويصلّح اللي فيه لحد ما يبقى نضيف.

    صفحة الـ Skill الرسمية على GitHub ↗
  2. 01

    ركّبها في Claude Code

    افتح Claude Code واكتب الأمرين دول واحد ورا التاني، وبعدها الـ Skill تبقى جاهزة.

    /plugin marketplace add Motionsites-AI/claude-skill /plugin install motionsites-web-builder@motionsites

  3. أو في Claude.ai

    نزّل ملف motionsites-web-builder.zip من آخر Release على صفحتهم. في Claude افتح Customize ثم Skills ثم + ثم Create skill ثم Upload a skill، اختار الملف وشغّل الـ Skill. لازم Code execution يكون شغال من Settings ثم Capabilities.

    نزّل ملف الـ zip من آخر Release ↗
  4. 02

    اطلب موقعك

    مش محتاج تكتب اسم الـ Skill. اطلب موقع عادي وهي هتشتغل لوحدها، واوصف البراند والإحساس اللي عايزه في سطر أو اتنين. مثال من صفحتهم:

    Build a landing page hero for a luxury sleep-tracking ring.
  5. 03

    خلّيه يشوف شغله

    عشان Claude يقدر ياخد سكرين شوت للموقع ويصلّحه بنفسه، ركّب Playwright مرة واحدة:

    pip install playwright && python -m playwright install chromium

  6. عايز موقع لبراندك؟

    لو عندك براند ومش فاضي للتركيب والتجربة، ابعتلي على الواتساب وقولّي البراند بتاعك بيعمل إيه، وأنا أعملهولك.

    عايز موقع لبراندك؟ كلّمني على الواتساب ↗

نصايح صغيرة

  • الـ Skill مجانية، بس استخدام Claude Code ممكن يحتاج اشتراك في Claude.
  • الأمثلة والفيديوهات اللي جوه الـ Skill ملك MotionSites: ينفع تستخدمها في المواقع اللي بتبنيها (حتى لعملاء)، بس ماينفعش تبيعها أو توزّعها كمجموعة.
  • الصور اللي في الريل أمثلة من تصاميم MotionSites وصفحتهم على GitHub.
