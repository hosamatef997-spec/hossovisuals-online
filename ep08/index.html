نزّل باك Skills بأمر واحد

خطوات الحلقة التامنة من «بتعلّم Claude قدامكم»: يعني إيه Plugin، وإزاي تنزّله من المتجر الرسمي بأمر واحد، وتشوف الـ Skills اللي جواه، وتشيله لو مش عايزه.

Watch the reelشوف الريلAll episodesكل الحلقات
  1. 01

    يعني إيه Plugin؟

    الـ Plugin باك جاهز بيضيف لـ Claude Code كذا حاجة مرة واحدة: Skills و Agents و Hooks و MCP servers. بتنزّله من متجر (marketplace)، وأشهرهم المتجر الرسمي claude-plugins-official.

    صفحة الـ Plugins الرسمية ↗
  2. 02

    افتح PowerShell

    الأوامر دي بتتكتب في PowerShell على ويندوز (أو Terminal على الماك) على طول، من غير ما تفتح Claude Code.

  3. 03

    نزّل الباك

    الاسم اللي قبل @ هو الباك، واللي بعدها هو المتجر. استنى لحد ما يقولك Successfully installed. ده باك HyperFrames الرسمي للفيديو بالكود.

    claude plugin install hyperframes@claude-plugins-official
  4. 04

    شوف جواه إيه

    هيطلعلك كل الـ Skills اللي جوه الباك بأساميها (الباك ده فيه 21 Skill)، وكمان كام توكن بياخدوا.

    claude plugin details hyperframes@claude-plugins-official
  5. 05

    اطلب وهو يختار

    اسأله عن الحاجة اللي عايز تعملها، وهو بيقرا أوصاف الـ Skills ويرشّحلك المناسب. أو افتح claude واطلب عادي، وهو يفتح الـ Skill لوحده.

    claude -p "Which installed skill fits a 10 second motion video made with code? One short line."
  6. 06

    الباكات اللي عندك

    يطلعلك كل الـ Plugins المتسطّبة على جهازك.

    claude plugin list
  7. 07

    شيله لو مش عايزه

    claude plugin uninstall hyperframes@claude-plugins-official

نصايح صغيرة

  • لو قالك إن المتجر مش موجود، ضيف المتجر الرسمي الأول بأمر marketplace add، وهتلاقيه كامل في الملف.
  • جوه Claude Code تقدر تكتب /plugin وتختار الباك من قايمة بدل الأوامر.
  • نزّل من مصادر بتثق فيها بس: الـ Plugin بيضيف تعليمات وأدوات Claude بينفّذها.
