Learning Claude in public · MOTIONبتعلّم Claude قدامكم · MOTION

اعمل أي ريل موشن زي ما هو، باسمك وصورتك

الطريقة اللي عملت بيها الريل: Claude بيقطّع الفيديو فريم فريم، ويبني نفس الحركات بالكود، وبعدين بيحط اسمك وصورتك وألوانك. معاك السكيل نفسه تنزّله وتشتغل بيه.

All episodesكل الحلقات
  1. 01

    جهّز الأدوات

    محتاج Claude Code (من تطبيق Claude على الكمبيوتر، تبويب Code)، وNode.js، وffmpeg. مش عارف تنزّلهم؟ افتح Claude Code واكتبله الرسالة دي، وهو هيعملهم معاك خطوة بخطوة:

    نزّلي Node.js وffmpeg على جهازي، واتأكد إن الأمر npx hyperframes --help شغال.
    claude.ai/download ↗
  2. 02

    نزّل السكيل

    حمّل الملف، وفكّه جوه فولدر السكيلز بتاع Claude: ‎~/.claude/skills/motion-copy‎ (على ويندوز: C:/Users/اسمك/.claude/skills/motion-copy). جواه الطريقة كاملة، وأداتين بيقطّعوا الفيديو لصور، وكود الحركات.

    حمّل motion-copy.zip ↗
  3. 03

    ملف المشروع جاهز

    دي ملفات ريل «بنظام واضح» نفسه: الفيديو كله كـ HTML، والسكريبت اللي بيكتبه بكل التوقيتات والألوان. افتح الفولدر في Claude Code وقوله: «غيّر الكلام والألوان لهويتي وارندره 4K».

    حمّل system-project.zip ↗
  4. 04

    جهّز الفيديو اللي عاجبك

    حط الفيديو اللي عايز تعمل زيه في فولدر على جهازك، ومعاه صورة ليك. خده كإلهام بس: متاخدش صوته ولا اسم صاحبه، وحط هويتك إنت.

  5. 05

    اكتبله الطلب

    افتح Claude Code على الفولدر ده، وانسخ الرسالة دي وغيّر الحاجات اللي بين القوسين:

    استخدم سكيل motion-copy واعملي الفيديو ده زي ما هو بالظبط، كل حركة وكل زوم، بس باسمي [اسمك] وشغلي [شغلك] وصورتي [اسم الصورة]، وبألواني [ألوانك]: [اسم الفيديو]
  6. 06

    سيبه يقارن

    Claude هيقطّع الفيديو كل عُشر ثانية، ويبني نسختك، وبعدين يحطها جنب الأصل ويصلّح أي فرق. لو شفت حاجة مش زي الأصل، قوله عليها بالثانية: «في ثانية 6 الكلام داخل من الناحية الغلط».

  7. 07

    خده جاهز

    في الآخر بيطلّعلك الفيديو 60 فريم، والصوت متظبط على مستوى إنستجرام. عايزه بألوان تانية؟ قوله: «نفس الفيديو بالظبط بس بألوان [ألوانك]».

  8. 08

    خد البرومبتات جاهزة

    برومبتات الستاشر موشن اللي في الريل، وبرومبت القطرة، كلها في صفحة واحدة. انسخ البرومبت، وغيّر اللي بين القوسين لهويتك، وابعته.

    البرومبتات ↗

نصايح صغيرة

  • كل ما الفيديو اللي بتديهوله أوضح، النسخة بتطلع أقرب للأصل.
  • عايز صوتك على الفيديو؟ اكتب الكلام بالمصري زي ما بتتكلم بالظبط، وإلا الصوت هيطلع خليجي أو فصحى.
  • إنستجرام وتيك توك بيشغّلوا لحد 60 فريم، فاعمل نسخة النشر 60.
