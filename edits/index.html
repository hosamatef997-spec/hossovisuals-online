`Edits`على الكمبيوتـــر

يوم الخميس 5 نوفمبر 2026 إنستجرام نزّلت تطبيق المونتاج Edits على الماك، مجاني. وكمان Claude Code يقدر يمنتج جوّاه. دي كل حاجة عنه، وكل نقطة بمصدرها.

All episodesكل الحلقات
  1. 01

    إيه الجديد؟

    Edits، تطبيق المونتاج بتاع إنستجرام اللي نزل على الموبايل في أبريل 2025، بقى ليه نسخة للكمبيوتر على macOS، وتحميلها مجاني (صفحة Edits الرسمية + MacRumors).

  2. 02

    فيه إيه؟

    تايم لاين بكذا تراك، Keyframes للانتقالات، موجة الصوت قدامك عشان تقطع على الإيقاع، تقسيم وقص أسهل، تستورد LUTs وخطوطك، وكابشن تلقائي من غير حد (MacRumors + TechCrunch).

  3. 03

    التصدير

    تصدّر 4K من غير علامة مائية، رأسي أو أفقي، وتنشر على إنستجرام على طول أو تنزّل الفيديو لأي منصة تانية (صفحة Edits الرسمية + MacRumors).

  4. 04

    محتاج جهاز إيه؟

    ماك بمعالج Apple silicon، يعني M1 أو أحدث، وحساب إنستجرام. مفيش نسخة ويندوز ولا لينكس لحد دلوقتي (صفحة Edits الرسمية + 9to5Mac).

  5. 05

    لسه ناقص

    إنك تكمّل نفس المشروع بين الموبايل والماك لسه مش موجود، وMeta بتقول إنه جاي وإن النسخة دي هتتحدّث كل أسبوع. الأصوات وستايلات الكتابة المحفوظة من الموبايل موجودة على الماك.

  6. 06

    Claude جوّه Edits

    Edits للماك جوّاه Server تحكم بيتكلم MCP، مستخبّي في الإعدادات: Edits ← Settings ← Automation ← Enable Automation Server، وبيديك Access token. ده اللي بيخلّي Claude Code يتحكم في المشروع: يقطّع على الإيقاع، ويحط captions ونصوص، ويعمل انتقالات وKeyframes، ويظبط الصوت، ويصدّر (insta-edits-for-claude على GitHub + The Breakdown).

  7. 07

    إزاي تربطه

    محتاج: ماك M1 أو أحدث، وEdits مفتوح ومسجّل دخول، وClaude Code (مش claude.ai في المتصفح). شغّل الـ Server من الإعدادات وانسخ الـ token، وبعدين ركّب أداة ربط مستقلة زي insta-edits-for-claude (مفتوحة المصدر، اقرا الكود قبل ما تركّبها) وادّيها الـ token لما تطلبه. بعدها اطلب من Claude مثلًا: «اعمل من الكليبات دي ريل 30 ثانية على الإيقاع بكابشن وصدّره». الأداة بتقول إن Edits بيفتح 274 أداة لما يكون فيه مشروع مفتوح.

    github.com/faisalkhanzemi/insta-edits-for-claude
  8. 08

    خلّي بالك

    الربط ده مش رسمي: الأدوات دي مش من Anthropic ولا Meta، والـ Server نفسه مش متوثّق، فممكن يبوظ مع أي تحديث لـ Edits. خلّي الـ token سر. مش كل خصايص Edits متاحة من خلاله، وأغاني مكتبة Edits ممكن تطلع ساكتة لو التصدير اتعمل من Claude، فصدّر من البرنامج نفسه لو الأغنية مهمة.
